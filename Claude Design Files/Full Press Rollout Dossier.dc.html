Fold the layer into the source

foundation · de-risk before pixels

press.css calls itself "the proposed hub.css diff." Wave 21 makes that literal: merge the values and class faces into the frozen chain, load the fonts the system now assumes, and put the gates in place — so waves 22–25 are pure application.

21.1
Merge press.css → hub.css

Fold the 76 lines into @jkos/design/tokens/hub.css — values and class faces only, token names frozen (§13.1). Retire the standalone file once merged.

fence · no renamed tokens, no new hex
21.2
Load the assumed fonts suite-wide

Promote Fraunces from per-app copy to a primitive input in buildJkOSTheme; flip the --hub-font-serif default. Ensure Big Shoulders loads in dark for the seg verdict (§15.2).

risk · always-on webfont weight budget
21.3
Rewrite the doctrine in DESIGN.md

Document the Voice split (print / mono / tube), seg-splits-by-face, folio-vs-tape, the rules ladder, the colophon, and entrance physics. Extend the Fence DO / DON'T.

governance · the spec the apps cite
21.4
Extend the gates

Add a face check to CI: .seg font-family flips with data-mode, both faces build, no fresh hardcoded hex. Keep test/responsive.mjs green.

gate · catches drift, not taste
21.5
Regenerate every token mirror

Run sync:tokens for each app so public/jkos-tokens.css matches hub.css byte-for-byte; assert parity in CI.

exit criterion · one source, N identical mirrors
22

Re-cut the primitive layer

@jkos/ui · the big rehaul

This is where "most primitives get rehauled." Component APIs stay stable — only their faces change — so apps inherit the new voice for free. Each task is one primitive family.

22.1
The Voice — labels & text buttons

Re-set the .jk-lab ladder and .jk-tbtn in Fraunces. Deliberately keep .mono-eyebrow and .jk-pill in mono — the machine still speaks mono.

22.2
Letterpress the chips

.jk-bubble becomes serif caps with ink pressed in on paper / halation on the tube — via existing tokens, no new physics. <Bubble> API unchanged.

22.3
Ship the rules ladder

New .jk-rule / -strong / -double as an <hr> face; add a <Rule weight> component. Hairline for rows, ink for chapter heads, double for contents / colophon.

22.4
Print marks — folio vs tape

Re-cut .stamp in serif; add .jk-folio / .jk-folio-no + <Folio>. Audit every .label-tape — content names become folios; tape stays machine-chrome only.

judgement call · the audit spills into wave 23
22.5
The seg verdict — split by face

.seg keeps Big Shoulders + glow on the CRT and prints Fraunces lining tabular figures on paper. Confirm the readout stays legible at dense sizes on paper.

open · Fraunces figures everywhere, or keep seg where tight?
22.6
Off-states carry the idiom

.jk-async-note → serif italic; AsyncView copy goes to the print idiom ("Setting type…", NO SIGNAL stamp on error). Retire the two app-local .muted copies + MatchPanel's hardcoded one.

22.7
Colophon + player title

Add .jk-colophon + <Colophon>; weight .pb-title like a title in @jkos/player.

22.8
Parity check the layer

Render @jkos/ui against the Canvas + Full Press sheets in both faces; they are the acceptance reference for this wave.

23

Roll out per app

dependency order · smallest & shared first

Most of each app comes free from wave 22. What remains is per-app judgement: the folio audit, replacing any hand-rolled serif with the primitive, re-setting headings on the editorial grid, and an off-state copy pass — then both-face QA and a fresh token mirror.

Per-app checklist

folio audit · primitive serif · editorial grid · off-state copy · both-face QA · regenerate mirror

23.1
jkauth — the letterpress form

First: smallest surface, shared by every app, proves the Voice end-to-end. Sign-in as a printed form.

23.2
papyros — the biggest consumer

Library index as "Contents," book detail, the player-as-colophon, MatchPanel copy. Highest surface area — most of the audit lands here.

23.3
kouros — reface to the Voice

Voice + folio + off-state pass. Retire its local .muted copy in favour of the primitive.

23.4
BeigeBoard — the workshop

Shell + calendar. .jk-cards-* stay byte-identical (kit-owned), so this is voice / chrome / folio only — low risk.

23.5
ORDECK — dashboard widgets

Reface chrome, folio, seg. Keep bespoke reel-spin / ticker motion — those are app-owned, not primitives.

23.6
SylibOS — out of scope

Untouched by standing rule. Recorded here only so the roster is complete and no one migrates it by reflex.
